# ISO-to-MOV
### 用视频安装操作系统（ISO 转 数据流视频）

> **转?! 转?!**
> 将任意操作系统 ISO 镜像（Windows / Linux / macOS）的数据流，通过 Python 渲染并合成带完整 UI 的 1080P 滚动数据视频！

---

## 项目简介

ISO-to-MOV 是由 Xlord 编写的数据视像化工具。

(我曾经挂在OCS上,但现在存档了)

它利用 Python 提取 ISO 镜像或挂载目录中的二进制字节流，并将其实时映射成像素画面，最后配上 UI 界面，压制成高码率视频。每一帧画面里闪烁的色彩，都是真实、完整存在的操作系统代码。

---

## 核心特性

- **全格式与全系统支持**：支持 .iso / .img / .dmg 等镜像，或直接读取已挂载的目录。
- **高性能渲染架构**：静态 UI 预渲染（PIL） + 动态数据切片（Numpy/OpenCV），提高压制性能。
- **跨平台免 Root 降级**：优先尝试系统挂载，若无权限自动平滑降级至 bsdtar 字节流直读。
- **信息隐写与视像化**：将真正的操作系统二进制字节映射为滚动像素数据流。
